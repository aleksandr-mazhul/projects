# meal-plan-3100

Рабочая папка плана питания на **3100 ккал**.

На Linux это `~/projects/personal/meal-plan-3100`. В GitHub этого каталога раньше не было — cloud agent его не видел. Сюда кладём сам рацион, сверку с нормами и правки.

Нормы взяты из консультации: `health/План_здоровье_и_тренировки` (Том II — Питание). Числа — в [`norms.md`](norms.md).

## Как работаем

1. Кладём сюда актуальный рацион (меню, таблицу, заметки — как есть на машине).
2. Считаем день: ккал / белок / жиры / углеводы.
3. Сверяем с `norms.md` и правим порции и состав, пока день не сходится.

Файлы рациона с Linux в git пока не попали. Добавь их в эту папку (коммит/пуш или вложение в чат) — дальше разбираем уже конкретное меню, а не общие цифры.
