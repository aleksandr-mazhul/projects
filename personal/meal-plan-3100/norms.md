# Нормы питания

Источник: консультация врача-тренера, Том II. Папка названа `meal-plan-3100` — рабочая цель по энергии **3100 ккал/день**. В тексте консультации фиксированной цифры 3100 нет: там база ~2500–2600 плюс расход тренировки, который сильно плавает по дням.

## Человек

| | |
|---|---|
| Возраст | 18 |
| Рост | 185 см |
| Вес | 71 кг |
| Цель | мышцы +, жир слегка −, скалодром + велосипед |

## День (рабочий ориентир)

| | Цель | Комментарий |
|---|---|---|
| Энергия | **3100 ккал** | База консультации ~2500–2600 без тяжёлой тренировки. 3100 — профицит под набор при обычном/среднем дне. |
| Белок | **140–150 г** | ~2 г/кг. Не обязан каждый день в точку, в среднем да. |
| Жиры | **70–80 г** | Минимум 0,8 г/кг ≈ 60–70 г. |
| Углеводы | **остаток** | Не резать. При 3100 / 145 г белка / 75 г жира это примерно **460 г**. |
| Вода | **2,5–3 л** | 35–40 мл/кг в обычный день. |

При 3100 ккал / 145 г белка / 75 г жира / 460 г углеводов:

- белок ≈ 580 ккал (19%)
- жиры ≈ 675 ккал (22%)
- углеводы ≈ 1840 ккал (59%)

## Энергия по типу дня (консультация)

Базовый обмен ≈ 1800 ккал. Средняя активность без тренировки ≈ 600–800 → **2500–2600 ккал**.

Сверху по активности:

| Тренировка | Добавка |
|---|---|
| Скалодром | +700–1000 |
| Велосипед | +1000–1800 |
| Зал | +350–500 |
| Бассейн | +300–500 |

В тяжёлый велодень 3100 может быть мало. В день без нагрузки — уже явный профицит. Рацион один (3100), а дни разные: это надо будет учитывать, когда появится меню.

## Белок по приёмам (как в консультации)

Пример на 150 г: завтрак 30 / обед 40 / ужин 40 / перекусы 40.

После тяжёлой тренировки в течение часа: **25–40 г белка + углеводы** (рис + курица, творог + фрукты).

## Углеводы вокруг тренировок

- Не идти на велосипед и в зал натощак.
- За 2–3 часа — нормальный приём (рис/макароны + курица/индейка + овощи). Жирное перед тренировкой не есть.
- Если до старта < 1 часа — лёгкое: банан, питьевой йогурт, овсянка, тост, рисовые хлебцы.
- Скалодром > 2 часов: 20–40 г углеводов каждый час.
- Велосипед > 90 мин: 20–25 г углеводов каждые 25–30 **минут** (не километры). Ориентир 60–75 г/час.
- Гели Bombbar Energel: ~25–30 г углеводов на пакет; на самой нагрузке из геля нужны углеводы и натрий, не BCAA/белок.

## Вода на тренировке

| | |
|---|---|
| Зал | 700–1000 мл за тренировку (сейчас ~300 мл — мало) |
| Скалодром | 800–1500 мл |
| Велосипед летом | 500–750 мл/час |

## Ограничения из анкеты

- Сахар в быту не есть (акне). На длительной тренировке быстрые углеводы — топливо, не «сладкое вечером».
- Алкоголь и кофе нет.
- Готов считать калории и взвешивать еду (контрольные 14 дней).
- Самооценка рациона на консультации: «сколько хочу», ориентир ближе к **3500 ккал**; типичный день — сырники / мясо+рис / то же на ужин.

## Что сверяем, когда будет меню

1. День ≈ 3100 ккал (не 2200 и не «на глаз 3500»).
2. Белок 140–150 г без дыр в приёмах.
3. Жиры 70–80 г, не ужаты.
4. Углеводы закрывают остаток; вокруг тренировок — отдельно, не «голодный зал».
5. Сахар/мучное в быту не раздуваем; на вело/скалодроме углеводы по времени есть.
